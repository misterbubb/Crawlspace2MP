# Required DLLs

This folder should contain DLLs from your Crawlspace 2 installation. These are not included in the repository due to licensing.

## From `Crawlspace 2_Data/Managed/`

Copy these files:
- `Assembly-CSharp.dll`
- `UnityEngine.dll`
- `UnityEngine.CoreModule.dll`
- `UnityEngine.PhysicsModule.dll`
- `UnityEngine.AudioModule.dll`
- `UnityEngine.AIModule.dll`
- `UnityEngine.IMGUIModule.dll`
- `UnityEngine.InputLegacyModule.dll`
- `UnityEngine.VideoModule.dll`
- `UnityEngine.XRModule.dll`
- `UnityEngine.UI.dll`
- `UnityEngine.UnityWebRequestModule.dll`
- `Unity.InputSystem.dll`
- `Unity.XR.Management.dll`

## From `BepInEx/core/`

Copy these files:
- `BepInEx.dll`
- `0Harmony.dll`

## Default Game Location

```
C:\Program Files (x86)\Steam\steamapps\common\Crawlspace 2
```
