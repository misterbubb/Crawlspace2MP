# Crawlspace 2 Multiplayer

Online co-op for Crawlspace 2. Play through the game with friends using Steam networking. Supports up to 10 players.

## Features

- World-space VR multiplayer panel (host, join, invite, lobby codes)
- Proximity voice chat (Steam Voice)
- Real-time player sync (head, hands, body)
- Puzzle sync with per-player batteries
- Monster sync (Henry, Harold, Clown, Paintings)
- Ghost spectator mode on death
- Minimap indicators for all players
- Night progression saves for everyone
- Host migration on disconnect

## How to Play

1. Install BepInEx 5
2. Drop mod files into the correct folders
3. Launch through Steam
4. Complete Night 0 (tutorial) solo first
5. Host a game or join a friend from the VR panel

All players need the same mod version.

## Voice Chat

Steam Voice with proximity-based 3D audio. Toggle from the multiplayer panel.

## Bug Reports

Enable VerboseLogging in `BepInEx/config/com.crawlspace2.multiplayer.cfg`, reproduce the issue, and share `BepInEx/LogOutput.log`.
